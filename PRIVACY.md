# Privacy Policy - Time Zone Planner

Last updated: YYYY-MM-DD

Time Zone Planner is a ChatGPT/Codex plugin and a remote MCP server that converts times between time zones and finds meeting times. This policy describes what the server processes when you use the plugin.

## What is processed

When the plugin is used, ChatGPT or Codex sends the server the inputs of a tool call. These are values you supply in your request, such as dates and times, time zone names, participant names or labels, and working hours. The server processes them in memory only to compute the response and returns the result.

## What is not collected

- No accounts or logins. The service does not authenticate users.
- No cookies or similar identifiers.
- No analytics or tracking.
- No persistent storage. There is no database and tool inputs are not written to disk.
- No sharing with third parties. The server makes no outbound network calls.

## Logging

The server writes standard operational logs, such as timestamps, request paths and status codes. Tool arguments are not logged. The hosting provider that runs the server may separately log IP addresses and request metadata under its own privacy policy.

## Retention

Tool inputs are not retained. They exist only for the duration of a request. Operational logs are kept for the period set by the hosting provider.

## Your controls

Because the service stores no personal data about you, there is nothing to access, correct or delete on the server side. Avoid entering information you do not want processed, such as real names, if a generic label works. Conversation content held by ChatGPT or Codex is governed by OpenAI's policies, not this one.

## Children

The service is not directed to children and does not knowingly collect personal information from anyone.
